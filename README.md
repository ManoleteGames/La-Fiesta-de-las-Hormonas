# LA FIESTA DE LAS HORMONAS

"La Fiesta de las Homonas" es un juego de 16-bit para DOS (real mode) 
presentado en la "C:\DOS\CONTEST\" del MS-DOS Club https://msdos.club/

El objetivo del juego es conseguir que la chica que te gusta, Jessy, te acompañe a la fiesta de fin de curso,
para ello tendras que convertirte en popular, buena persona y aprobar todos los exámenes. Jessy no se va con
cualquiera.
Tus acciones tendrán consecuencias, ya que cada decisión moldeará tu estatus. Toma decisiones acertadas para 
que Jessy se fije en tí, de lo contrario pasará de tu culo y cumplirás 20 años siendo virgen (como en la vida 
real).

## 1. LICENCIA
   Como buen comunista (de momento, si me toca la loteria ya hablaremos), este juego es público, gratuito,
   y de código abierto. Úsalo como te venga en gana.
   
## 2. COMPILACION
   El código está desarrollado en lenguaje C y ensamblador utilizando el compilador Borland C 5.02
   
## 3. REQUISITOS
   El juego puede ser ejecutado en procesadores 286 o superiores de 16-bit. 640KB, ¿Quien necesita más?.
   Requiere tarjeta de video VGA.
      
## 4. USO
   Para ejecutar el juego puedes usar una máquina real con MS-DOS (a partir de 3.0) o cualquier emulador como
   DOS-BOX o PCem.
   Utiliza los cursores para desplazarte por la pantalla y la tecla enter para realizar acciones.

   También puedes jugarlo directamente en el navegador en el siguiente link:
   
   https://manoletegames.itch.io/la-fiesta-de-las-hormonas
